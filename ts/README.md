# @voxgig/apidef

Turns an OpenAPI 3 or Swagger 2.0 definition into the API model that
[`@voxgig/sdkgen`](https://www.npmjs.com/package/@voxgig/sdkgen) generates
client SDKs from: the entities, operations, fields and flows the definition
implies.

```sh
npm install @voxgig/apidef
```

The full README, covering usage, the `voxgig-apidef` command and
configuration, is in the repository:
[github.com/voxgig/apidef](https://github.com/voxgig/apidef#readme). The
documentation, from a tutorial to the model reference, is in its
[`docs`](https://github.com/voxgig/apidef/tree/main/docs) folder.
